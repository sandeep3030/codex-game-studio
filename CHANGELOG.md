
# Changelog

All notable changes to Codex Game Studio are documented here.

This project follows a simple versioning approach.

## [0.1.0] — Initial Release

### Added
- Initial Codex Game Studio repository structure.
- Root-level project instructions through `AGENTS.md`.
- Project charter and studio operating model.
- Four specialist agent configurations.
- Three reusable Codex skills:
  - Game Project Audit
  - Game Design Studio
  - Prototype Planner
- Initial Godot engine profile.
- Game Design Document template.
- Prototype planning template.
- Studio responsibilities and quality gates.
- Contribution and licensing documentation.

### Scope
- OpenAI Codex as the initial AI development environment.
- Godot as the first supported game engine.

### Status
Initial release preparation. Features must be validated before release publication.
