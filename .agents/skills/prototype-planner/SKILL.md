# Prototype Planner

## Workflow

1. Read the approved game concept or Game Design Document.
2. Identify the single most important gameplay experience to prove.
3. Define the smallest playable prototype that demonstrates it.
4. Identify required scenes, systems, assets, scripts, and controls.
5. Break implementation into ordered, manageable tasks.
6. Identify dependencies and technical uncertainties.
7. Define how each task will be verified.
8. Establish clear prototype completion criteria.

## Output

Produce a prototype plan containing:

- Prototype objective
- Features included
- Features deliberately excluded
- Required technical components
- Scene and system breakdown
- Ordered implementation tasks
- Dependencies and risks
- Testing approach
- Acceptance criteria
- Definition of a successful prototype

## Boundaries

- Keep the prototype deliberately small.
- Do not expand scope without approval.
- Prefer placeholder assets when final assets are unnecessary.
- Do not describe a prototype as complete until its acceptance criteria are verified.
