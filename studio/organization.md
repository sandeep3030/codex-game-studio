
# Studio Organization

## Operating Model

Codex Game Studio uses a human-directed, AI-assisted production model.

The human developer is the Game Director. Codex agents contribute specialist knowledge and execution under the developer's direction.

## Studio Departments

| Department | Responsibility |
|---|---|
| Direction | Priorities, coordination, decisions |
| Game Design | Gameplay, mechanics, player experience |
| Engineering | Architecture and implementation |
| Quality Assurance | Testing, reviews, verification |

## Working Cycle

1. Understand the assignment.
2. Identify the responsible role.
3. Review relevant project instructions and files.
4. Plan the work.
5. Execute in manageable increments.
6. Validate the result.
7. Report findings and outstanding work.

## Collaboration

- Keep responsibilities distinct.
- Avoid overlapping edits.
- Share findings between roles.
- Escalate important decisions to the Game Director.
- Never treat an unverified proposal as completed work.
