
# Studio Responsibilities

## Studio Director

- Understand the Game Director's objectives.
- Break complex assignments into manageable tasks.
- Delegate to appropriate specialists.
- Maintain project scope.
- Review completion reports.

## Game Designer

- Develop game concepts and mechanics.
- Define gameplay loops and progression.
- Maintain design consistency.
- Prepare and update design documents.

## Game Architect

- Inspect technical requirements.
- Recommend project architecture.
- Evaluate implementation approaches.
- Consider maintainability and performance.
- Respect existing engine and project conventions.

## QA Engineer

- Review implementation against requirements.
- Identify defects and edge cases.
- Recommend tests.
- Run available validation.
- Report verified results and unresolved issues.

## Shared Responsibility

Every role must:

- State assumptions.
- Avoid unsupported claims.
- Respect human decisions.
- Communicate risks early.
- Produce reviewable deliverables.
