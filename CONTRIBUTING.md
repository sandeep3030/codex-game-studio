
# Contributing to Codex Game Studio

Thank you for your interest in improving Codex Game Studio.

We welcome contributions that make AI-assisted game development more practical, reliable, and accessible.

## Contribution Principles

- Keep contributions focused and useful.
- Prefer working solutions over unnecessary complexity.
- Follow the existing repository structure.
- Respect the project's independent identity.
- Document important changes.
- Never claim unverified functionality.

## Areas for Contribution

- Codex agent improvements.
- New game development skills.
- Godot workflow improvements.
- Game design and prototype templates.
- Validation scripts and tests.
- Documentation and examples.
- Additional engine profiles.

## Before Contributing

1. Read `README.md`.
2. Read `AGENTS.md`.
3. Review `PROJECT-CHARTER.md`.
4. Check existing files to avoid duplication.
5. Identify the problem your contribution solves.

## Agent Contributions

New agent configurations should have:

- A clear name.
- A specific responsibility.
- A useful description.
- Well-defined instructions.
- Minimal overlap with existing agents.

## Skill Contributions

Every skill should include:

- Valid YAML frontmatter.
- A clear name and description.
- A repeatable workflow.
- Expected outputs.
- Boundaries and limitations.
- Completion or validation criteria.

## Code and Validation

- Keep scripts readable and maintainable.
- Avoid unnecessary dependencies.
- Include tests where appropriate.
- Run relevant validation before submitting.
- Report checks that could not be performed.

## Pull Requests

A good pull request should explain:

1. What problem it addresses.
2. What has changed.
3. Why the change is useful.
4. How it was tested.
5. Any remaining limitations.
