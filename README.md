# Codex Game Studio

**An AI-powered game development studio for OpenAI Codex.**

Codex Game Studio is an open-source framework that helps developers use OpenAI Codex as a coordinated game development team.

Instead of treating AI as a single coding assistant, this project organizes game development into focused responsibilities: game design, architecture, prototyping, quality assurance, and production planning.

## Our Vision

Make professional game development workflows more accessible through specialized AI assistance, reusable skills, clear development processes, and engine-specific guidance.

## Initial Focus

- **AI coding environment:** OpenAI Codex
- **First supported game engine:** Godot
- **Project approach:** Human-directed, AI-assisted development
- **Repository status:** Early development

## What This Project Aims to Provide

- Specialized Codex agents for game development responsibilities.
- Reusable skills for common game development tasks.
- Structured game design and prototyping workflows.
- Godot-specific development guidance.
- Templates, quality checks, and project documentation.

## Design Principles

1. Human developers remain in control of creative and technical decisions.
2. Every agent and skill must have a clearly defined responsibility.
3. Workflows should produce practical, reviewable outputs.
4. The framework should be modular and extensible.
5. Documentation and validation are part of the product, not afterthoughts.

## Project Status

This repository is under active initial development. Features will be added incrementally and tested before being presented as production-ready.

## Important Notice

Codex Game Studio is an independent, community-oriented open-source project. It is not an official OpenAI product and is not endorsed by OpenAI.
